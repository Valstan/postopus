### [2025-03-26] - Автоматический сбор статистики постинга и публикация в Тестовый полигон

**Что изменено:**
- Добавлен новый модуль `bin/rw/publish_stats.py` для публикации статистики ВКонтакте
- Модифицирован `start_paket.py`: статистика собирается ВСЕГДА при любом запуске
- Изменена логика обработки флага `stat`:
  - С префиксом `stat`: вывод подробной статистики в терминал
  - Без префикса `stat`: автоматическая публикация итогов в сообщество "Тестовый полигон" (-137760500)
- Все регионы теперь всегда передают данные о результатах постинга через `stat_mode=True`

**Затронутые файлы:**
- `bin/rw/publish_stats.py` (новый файл)
- `start_paket.py` (изменён)

**Причина изменения:**
- По требованию пользователя: статистика должна собираться при всех запусках постинга
- При запуске с префиксом `stat` — вывод в терминал
- При чистом запуске без `stat` — публикация результатов в пост в сообщество "Тестовый полигон" (https://vk.com/ititenskoegore)

**Влияние на другие модули:**
- `start_paket.py` теперь всегда вызывает `start()` с `stat_mode=True`
- Новый модуль `publish_stats.py` использует существующие функции `post_msg()` и `get_session_vk_api()`
- Обратная совместимость сохранена: функция `start()` по-прежнему поддерживает параметр `stat_mode`

**Обратная совместимость:**
- Полностью сохранена: старый код продолжает работать
- Изменено только поведение `start_paket.py` в части сбора и вывода статистики
- Функция `start()` и контроллеры остаются совместимыми
